2-Way Sync Engine
បញ្ជូនទៅម៉ាស៊ីនមេ (Push)

ប្រមូលទិន្នន័យ និងឯកសារមេឌាដែលបានបង្កើត/កែប្រែលើ PC នេះ បញ្ជូនឡើងទៅកាន់ម៉ាស៊ីនមេកណ្តាល។

ទាញពីម៉ាស៊ីនមេ (Pull)

ទាញយកបច្ចុប្បន្នភាពទិន្នន័យ និងរូបថតពីម៉ាស៊ីនមេកណ្តាល មកបញ្ចូលសមកាលកម្មក្នុង PC នេះ។

សមកាលកម្មទាំងសងខាង (Bidirectional Sync)

ដំណើរការ Pull ទិន្នន័យថ្មីពី Server ជាមុន រួចធ្វើការ Push ទិន្នន័យថ្មីពី PC នេះឡើងទៅ Server វិញដោយស្វ័យប្រវត្តិ។
